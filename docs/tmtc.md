# TC/TM 모의 링크

임무 계획 도구의 **TC/TM** 탭은 간단한 모의 위성을 돌린다.
- 선택한 궤도(run)와 선택한 지상국(패스 예측과 같은 선택)으로 교신 일정을 만든다.
- 교신 중에만 TM이 내려오고 TC가 올라간다.
- 시뮬레이션 시각은 브라우저의 Cesium clock이다. 타임라인을 재생해 패스를 지나가면 링크가 열린다.

## 동작

| 항목 | 내용 |
| --- | --- |
| 패킷 | CCSDS Space Packet(6바이트 기본 헤더). TM은 8바이트 2차 헤더에 온보드 시각(UTC ms)을 넣는다 |
| HK (APID 100) | 10초(시뮬레이션 시각)마다 모드, 실행 명령 수, 거부 수, 배터리 %, 저장량 % |
| 이벤트 (APID 101) | 명령 실행(EXECUTED)·거부(REJECTED)와 명령 코드 |
| TC (APID 200) | `NOOP`(1), `SET_MODE`(2, 인자: SAFE/NOMINAL/IMAGING), `TIME_TAG`(3, 실행 시각 ms + 안쪽 명령) |
| 교신 밖 TM | 온보드에 최대 720개 쌓였다가 다음 AOS에 재생(`replay`)으로 내려온다 |
| 교신 밖 TC | 지상에서 대기하다 다음 AOS에 올라간다 |
| 시계를 뒤로 돌리면 | 위성 상태를 처음부터 다시 시작한다 |

## 화면 표시

| 위치 | 내용 |
| --- | --- |
| 상단 칩 | 세션 동안 항상 보인다. 링크가 열리면 지상국·`TM↓`/`TC↑` 개수·LOS까지 남은 시간, 닫히면 다음 AOS까지 남은 시간과 대기 중인 TC 수. 누르면 TC/TM 도구가 열린다 |
| 지구본 시선 | 교신 중인 지상국과 위성을 잇는 실선. 패스 예측의 시선(점선)은 "보인다"는 뜻이고, 실선은 모의 링크가 열렸다는 뜻이다 |
| 교신 띠 | 지금 교신 중이거나 다음에 올 교신 하나를 궤도 위 띠와 AOS/LOS 핀으로 그린다. "다음 AOS로 이동"이 어디로 가는지 보여 준다. 패스 예측이 같은 패스를 이미 그리고 있으면 겹쳐 그리지 않는다 |
| 패킷 점 | 패킷이 오갈 때 시선 위를 지나가는 점. TC는 지상국에서 위성으로, TM은 위성에서 지상국으로 간다 |
| 다음 AOS로 이동 | 패널의 버튼. 시계를 다음 교신 시작 직후로 옮긴다 |

시선과 점은 "지상국 표시" 레이어를 끄면 함께 꺼진다. 칩은 남는다.

위성 수치는 특정 버스를 본뜨지 않았고, 운영자가 예상하는 방향으로만 움직인다.
- 촬영 모드는 배터리를 쓰고 저장량을 채운다.
- SAFE 모드는 배터리를 충전한다.
- 교신 중에는 저장량이 빠진다.
- 배터리가 5% 아래로 내려가면 스스로 SAFE 모드로 간다.
- 배터리가 10% 미만이면 IMAGING 명령을 거부한다.

코드는 `src/soda/tmtc/`에 있다.

| 파일 | 역할 |
| --- | --- |
| `packets.py` | 패킷 인코딩·디코딩 |
| `spacecraft.py` | 위성 상태 |
| `link.py` | 교신 일정 |
| `session.py` | 시뮬레이션 진행 |
| `hub.py` | 세션과 WebSocket 연결 관리 |

## API

| Method | Path | 설명 |
| --- | --- | --- |
| POST | `/api/v1/tmtc/session` | `{norad_id\|custom_id, start, end, station_ids}`로 세션을 새로 시작한다. 서버가 패스를 계산한다 |
| GET | `/api/v1/tmtc/session` | 현재 세션 상태 |
| DELETE | `/api/v1/tmtc/session` | 세션 종료 |
| WS | `/api/v1/tmtc/ws` | 받는 메시지와 보내는 메시지는 아래 표 |

WebSocket 메시지:

| 방향 | 메시지 |
| --- | --- |
| 클라이언트 → 서버 | `{"type":"clock","ms":…}`, `{"type":"tc","command":{"command":"SET_MODE","mode":"SAFE"}}` |
| 서버 → 클라이언트 | `status`(`contacts[]`: `aos_ms`·`los_ms`·`station_id`·`track_fixed_m`), `link`, `packet`(방향, APID, seq, hex, 해석값, `replay`), `queued`, `reset`, `dropped`, `error` |

세션은 서버에 하나뿐이다. 여러 브라우저 탭이 같은 세션을 본다.

외부 관제 소프트웨어(Yamcs 등)와의 UDP 연동은 넣지 않았다. 모든 동작은 SODA 안에서 끝난다.
